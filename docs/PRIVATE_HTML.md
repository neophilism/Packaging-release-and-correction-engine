# Private metadata HTML (partial PRC-005)

`renderPrivateMetadataHtml(prepared)` from `./private-html` is a data formatter, not authentication or a service. A host must first obtain a freshly authorized export through the accepted PrivateReleaseStore.exportPrivate flow, then apply ordinary private access controls. Caller snapshots, manifest hashes and this renderer's profile checks do not authenticate a principal or establish current rights/consent/editorial permission. The formatter does not call a resolver, database, filesystem or network and adds no durable permission fence.

The input is the existing exact five-field private prepared-export profile: schemaVersion, visibility, manifest, manifestHash and sourceCompanion. Bounded approved/private manifest, exact computed manifest hash and exact derived source companion are required. Input canonical UTF8 metadata is at most512KiB; rendered output is at most2MiB. Oversized inputs or expansion fail closed. The complete canonical metadata is retained as inert escaped text; labels display as literal JSON strings so control characters and Unicode remain explicit. The semantic table and headings contain no scripts, styles, links, forms, remote assets or artifact content bytes. A restrictive CSP meta element is defense in depth; escaping is the primary inertness boundary.

The return value contains detached UTF8 bytes, text/html charset, private visibility, SHA256 of the actual output bytes, and a separate canonical package metadata hash. Hashes are integrity identifiers, not signatures or authentication. The document is a historical snapshot; an approval displayed in metadata is not current execution/release authority, independent verification or publication receipt. Downloaded copies cannot be revoked by this library. No publication, transport, file persistence, binary content retrieval, PDF/OCR or external enablement is added.

Initial three local groups/typecheck pass using actual domain-prepared fictional exports, deterministic bytes/independent hash/detached mutation, inert malicious labels and Unicode, exact companion/hash/private-profile rejection and input budgets. Expanded bounds, installed public exports, full checks/source review/current-head CI remain pending. Semantic markup/text tests are not real-browser, assistive-technology or accessibility acceptance. Private hosting/authentication/current policy, content packaging/storage, browser/accessibility and deployed qualification remain separate.
